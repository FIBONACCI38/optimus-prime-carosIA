# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or a reproducible attack against a real system in a public issue.

Use GitHub's private vulnerability reporting for this repository if it is enabled. If it is not enabled, contact the maintainer privately through a verified channel listed on the maintainer's GitHub profile. Do not infer or guess an email address.

Include, where safe:
- affected version or commit;
- security impact and preconditions;
- minimal reproduction using a harmless fixture;
- suggested mitigation;
- whether any secret or personal data may have been exposed.

Do not perform testing against systems you do not own or have explicit permission to assess.

## Response expectations
The maintainer should acknowledge the report, validate impact in an isolated environment, coordinate remediation and disclosure, rotate affected credentials when applicable, and document the fix. No response time is guaranteed by this file.
